# CyScan

ML-based port scan risk detection system (Final Year Project, IIUM).

## Features
- Nmap-based port scanning through a Flask web interface
- ML models that classify scan results and assess risk
- Alert generation and scan logging

## Tech Stack
Python, Flask, Nmap, scikit-learn, pandas, Tailwind CSS

## Datasets
Not included because of size. Download them here:
- CIC-IDS2017: <link>
- UNSW-NB15: <link>

## Setup
1. Install [Nmap](https://nmap.org/download)
2. `pip install -r requirements.txt`
3. `python main.py`
