Some of the questions that could help you

What is an open port, and why is it a risk?

An open port is a network port that accepts connections. While many are necessary for services to run, they can be exploited by attackers if not secured properly, leading to unauthorized access or data breaches.

Does CyScan store any of my data?

No. Since CyScan is a simulated tool for learning, it does not collect, store, or transmit any personal or scanned data.

How accurate is the machine learning model used in CyScan?

CyScan uses a simplified ML model for demonstration purposes. It highlights concepts like anomaly detection and risk classification, but it’s not designed for real-world deployment accuracy.

Is CyScan suitable for classroom use or student projects?

Absolutely! CyScan is built for educational use and works well for classroom demos, workshops, or cybersecurity learning projects.

Who created CyScan?

CyScan was developed as a student-led project to educate others on network security fundamentals and the role of machine learning in threat detection.

Do I need to install anything to use CyScan?

No installation is required. CyScan runs entirely in your web browser and can be accessed from any modern device with internet access.
